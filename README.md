# TrustCircle: Verified Stays

Build a clean, modern, and crisp single-page web application called **TrustCircle**.

### Core Purpose

TrustCircle helps students find safe PGs, hostels, and flatmates by showing verified Trust Scores based on real past residents — not anonymous reviews or broker claims.

### Target Users

College students looking for safe accommodation.

### Keep the design extremely clean and minimal

- No clutter

- No unnecessary sections

- No long text

- No extra features

- Focus only on clarity and trust

### Must-have sections (only these):

1. **Hero Section**

   - App name + short tagline

   - One clear sentence explaining what it does

   - Primary CTA button: “Check Trust Score”

2. **Search / Trust Score Card** (Main highlight)

   - Simple search bar (PG/Hostel name or location)

   - After searching, show a clean Trust Score card with:

     - Overall Trust Score (out of 100)

     - Safety Score

     - Landlord Behavior Score

     - Number of verified reviews

   - Color-coded score (Green = Safe, Yellow = Average, Red = Risky)

3. **Second Standout Highlight: Verified Resident Badge**

   - A small but powerful section showing “Only verified past residents can rate”

   - Visual badge or icon that reinforces authenticity

   - Short line: “No fake reviews. No brokers. Only real students.”

4. **How it works** (Maximum 3 short steps)

   - Step 1: Search any PG/Hostel

   - Step 2: See verified Trust Score

   - Step 3: Make a safer decision

5. **Footer**

   - Very minimal

   - Just “Built for students • Privacy First”

### Design Requirements

- Extremely clean and modern

- Soft white background with subtle indigo/purple accents

- Excellent typography

- Generous spacing

- Rounded cards with soft shadows

- Mobile-first and fully responsive

- Premium but simple feel

- No glassmorphism overload, no heavy animations

### Two Key Highlights that must stand out:

1. **Trust Score Card** — Make this the most visually strong and clear element on the page.

2. **Verified Resident System** — Clearly communicate that only real past residents can leave reviews.

### Important Constraints

- Keep everything crisp and focused

- Do not add extra features like chat, login, map, filters, or profiles

- Do not add long paragraphs

- Prioritize clarity and trust over complexity

Generate a beautiful, minimal, high-quality frontend using HTML + Tailwind CSS. The page should feel trustworthy, calm, and student-friendly.
